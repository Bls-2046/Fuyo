<h1>Fuyo</h1> 

**星辅天衢阔，泽佑百卉生。云移千嶂暗，露结一灯明。**

<h2>功能</h2>

✅ 通过学号登录校园网并获取个人信息

✅ 设置日程安排到点桌面显示和 ❌ 自动发送微信提醒

❎ DeepSeek

❎ 上传网页图标和 url 快速访问网页；

❎ 密码箱

<h2>很随意的使用说明</h2>

```bush
git clone https://github.com/Bls-2046/Fuyo.git
```

前后端分离, C/S 架构

前端: Swing + JavaFX + Vue: vite v6.2.0

后端: Spring Boot v3.4.3

自动化: Python [3.13.2](https://www.python.org/downloads/release/python-3132/)

JDK: 23
